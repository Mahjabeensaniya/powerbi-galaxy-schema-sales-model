# powerbi-galaxy-schema-sales-model
Designed a Galaxy Schema data model in Power BI using multiple fact tables, shared dimensions, Power Query transformations, DAX measures, and interactive sales analytics reporting.

This project focuses on data modeling in Power BI using a Galaxy Schema (Fact Constellation) architecture. The solution integrates multiple fact tables and shared dimensions to support sales, inventory, campaign, and order process analysis.

Key Concepts Applied: Galaxy Schema (Fact Constellation) Modeling, Fact & Dimension Table Design, Data Granularity and Relationship Modeling, Power Query Transformations, ETL and Data Preparation, Factless Fact Tables, Relationship Management, Business KPI Development, Basic DAX Measures, Sales & Profitability Analytics, Interactive Dashboard Design

Data Model Components

Fact Tables: Sales, Inventory, Campaign, Order Process, Sales Targets, Factless Mapping Table

Dimension Tables: Date, Product, Customer, Campaign, Location, Order Flag

Dashboard Insights:

The final dashboard provides insights into: Sales Performance Over Time, Product Profitability, Profit Margin Analysis, Regional Performance, Customer Metrics, Order Trends, Tools & Technologies, Power BI, Power Query, DAX, Dimensional Modeling, Data Visualization
